# Contributing

Develop on `develop`. Use `feature/` branches only when requested, with pull requests targeting `develop`.

Keep the package independent of ROS. Pass sources, authentication and reference mappings explicitly.

Tests and examples must run offline without credentials or private reference data.

Edit `README.md` directly. Regenerate and commit `man/*.Rd` and `NAMESPACE` after changing roxygen documentation.

Run the checks in [DEVELOPMENT.md](DEVELOPMENT.md) before requesting review.
